Installed

Open a new terminal and try it:

echo 'println("hello")' > hello.sb
subi hello.sb
subc hello.sb -o hello && ./hello
sub  hello.sb python

man subi has the rest. To remove the toolchain again:

sudo rm -rf /usr/local/bin/sub /usr/local/bin/subc \
/usr/local/bin/subi /usr/local/lib/sub \
/usr/local/share/doc/sub-lang \
/usr/local/share/man/man1/sub*.1
