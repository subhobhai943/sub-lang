SUB Language

This installs the SUB toolchain into /usr/local:

  • subi — the interpreter and REPL. It is the language specification: what it prints, and the status it exits with, is what every other backend is tested against.
  • subc — the native compiler.
  • sub — the transpiler, to thirteen other languages.

The standard library goes to /usr/local/lib/sub/stdlib, where import finds it, and the manual pages to /usr/local/share/man.

/usr/local/bin is on the default PATH, so the three tools are available in a new terminal as soon as this finishes.
